# 图片参考图与知识库隔离

修复日期：2026-09-21。

图片生成页的本地参考图使用 `POST /api/v1/tasks/{task_id}/image-references`，以当前任务的附件保存。接口校验任务访问权限、归档状态、图片类型和 30 MiB 大小上限；返回可预览的素材表示，生成请求仍通过 `reference_asset_ids` 引用。

上传只创建媒体资源与文件引用，不创建 `LibraryItem` 或知识检索分块。知识库列表、产品目录不会因此增加记录。参考图不能用于其他任务；当前任务的预览通过专用下载接口进行访问校验。文件持久保存以支持已有生成请求和记录引用，不在取消选择时删除文件。

前端把本地参考图与企业目录存放在两个独立列表中。刷新企业目录不影响当前已上传参考图和参考图数量限制。参考图选择仍保持原来的页面会话行为，不从历史生成记录自动恢复旧选择。

知识库弹窗每次打开重新请求完整可见目录；空库也允许打开刷新。请求期间显示加载状态，失败后提供重试并禁止确认陈旧列表。读取成功同步更新父表单的产品与资料列表，并保留已选项。

已有通过旧接口入库的图片不自动删除或迁移，正式知识库上传与视频工程上传不变。

验证：`tests/test_content_image_reference_uploads.py` 覆盖上传、预览、参考图传入生成模型、知识库零新增、无检索分块、权限、跨任务引用及无效文件；前端 `scripts/image-reference-library-browser.test.mjs` 覆盖空库刷新、新资料显示、选择保留、失败重试、新上传接口和刷新后的参考图保留。后端测试使用隔离数据库与测试模型，浏览器测试拦截全部真实写请求。
